# Bot 33401 — Test Script

Test script(s) for the bot of team 33401 for the FTC Biobuzz 2026-2027 season, used to test driving, intake, shooting, and shooter's speed adjustments.

## Controls

| Controller input | Action |
|---|---|
| Left stick (X/Y) | Move the robot |
| Right stick | Rotate the robot |
| Right trigger | Activate the intake |
| Right bumper | Shoot |
| Left bumper | Boost speed |
| D-pad Up / Down | Increase / decrease the shooter's target speed |
| D-pad Left / Right | Increase / decrease the shooter's minimum speed |
